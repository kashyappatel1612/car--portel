================================================================================
AutoSmart AI - Project Requirements & Dependency Specification
================================================================================

1. SYSTEM & RUNTIME REQUIREMENTS
--------------------------------------------------------------------------------
- Operating System      : Windows 10/11, macOS, or Linux
- Node.js Runtime       : v18.0.0 or higher (v20+ / v24+ recommended)
- Package Manager       : npm v9.0.0 or higher (or yarn / pnpm)
- Database              : MongoDB v6.0+ (Optional: in-memory MongoDB fallback
                          is automatically provided via mongodb-memory-server)
- Web Browser           : Modern evergreen browser (Chrome, Firefox, Edge, Safari)
- Network Ports         :
    * Backend API       : Port 5000 (http://localhost:5000)
    * Frontend Web App  : Port 3000 (http://localhost:3000)


2. BACKEND DEPENDENCIES (Node.js / Express.js)
--------------------------------------------------------------------------------
# Production Dependencies (backend/package.json)
express                 ^4.21.2     # REST API web application framework
mongoose                ^8.9.3      # MongoDB object modeling and schema validation
mongodb-memory-server   ^10.1.0     # In-memory zero-config MongoDB database fallback
jsonwebtoken            ^9.0.2      # JWT user authentication and session tokens
bcryptjs                ^2.4.3      # Secure password hashing and salting
cors                    ^2.8.5      # Cross-Origin Resource Sharing middleware
helmet                  ^8.0.0      # Security headers middleware
dotenv                  ^16.4.7     # Environment variable configuration loader
morgan                  ^1.10.0     # HTTP request logger middleware

--------------------------------------------------------------------------------

JWT_SECRET=autosmart_jwt_secret_dev_key_2026
NODE_ENV=development

CLOUDINARY_API_KEY=your_cloudinary_api_key_optional
CLOUDINARY_API_SECRET=your_cloudinary_api_secret_optional


5. FUNCTIONAL & FEATURE REQUIREMENTS
--------------------------------------------------------------------------------
- Vehicle Catalog & Multi-attribute Search / Filtering
- Algorithmic Smart Score (0-100) based on Safety, Mileage, Power, Cost, Resale
- Side-by-Side Car Comparison (up to 4 cars)
- AI Car Recommendation Engine & Guided Questionnaire
- Car Loan EMI Calculator (with Recharts breakdown)
- 5-Year Total Ownership Cost Calculator
- Used Car Fair Market Valuation Estimator
- Seller Listing Portal with Admin Moderation & Approval Queue
- Role-based Access Control (Buyer / Seller / Admin)
